# The 4D continuum Yang–Mills existence hypothesis — honest status map

This document accompanies the Lean module
`lean/YMGap/Continuum/FourDExistence.lean`, which states the 4D continuum
Yang–Mills Osterwalder–Schrader (OS) existence assumption as an explicit
Lean `structure` (`ContinuumYMExistence` / `ContinuumYMWithGap`) — the
honest alternative to a `True` stub for the final mass-gap theorem.

## 1. This is the Clay Millennium Problem, and it is OPEN

The statement formalized in `ContinuumYMExistence` — that there exists a
4D continuum Yang–Mills measure `μ_∞` satisfying the OS axioms, generated
by gauge-invariant curvature observables, with O(4) rotation restoration,
correct UV (asymptotically free) behaviour, and nontriviality — **is the
Yang–Mills existence and mass-gap problem**, one of the Clay Mathematics
Institute Millennium Problems. It is **open**. Nothing in this repository
proves it.

The Lean structure is therefore a **hypothesis**: it is assumed wherever
it appears as an argument (e.g. `ym_mass_gap_of_existence` takes it as the
explicit hypothesis `H`). The deliverable is a precise *statement* of the
assumption, never a proof of it. There is no `sorry` standing in for the
existence proof, because the structure is not claimed to be inhabited for
the real Yang–Mills measure — that inhabitant is exactly the open problem.

## 2. What IS rigorously proven in the mathematics literature

The following are genuine, refereed results. None of them closes the 4D
problem; each clarifies how far the rigorous frontier reaches.

- **2D Yang–Mills: complete.** 2D YM is fully constructed and solved
  (Driver, Sengupta, Lévy; the partition function and Wilson-loop
  expectations are explicit). The OS / reflection-positivity structure is
  understood. This is the only spacetime dimension where YM existence is
  unconditionally settled.

- **3D φ⁴: complete (constructive QFT).** The superrenormalizable scalar
  φ⁴₃ theory satisfies all OS axioms (Glimm–Jaffe, Feldman–Osterwalder,
  Magnen–Sénéor). This is a scalar field, not a gauge theory, but it is
  the model case that the OS-axiom program *can* be carried out in
  dimension > 2.

- **3D Yang–Mills via stochastic quantization (2024).** Chandra–Chevyrev–
  Hairer–Shen (*Inventiones* 2024) construct the 3D YM measure via the
  stochastic-quantization (Langevin / regularity-structures) dynamics and
  establish gauge-covariant state space and a Markov process. This is a
  landmark, but it is **dynamics, not the full OS measure with the mass
  gap**: it constructs a candidate measure / process, not a proof that the
  reconstructed Hamiltonian has a spectral gap.

- **4D Yang–Mills: ultraviolet only.** Bałaban's program (1980s) and
  Magnen–Rivasseau–Sénéor (1993) control the **UV (short-distance) limit**
  of 4D lattice YM in a finite volume with a renormalization-group /
  cluster expansion. This gives uniform bounds and asymptotic freedom in
  the UV, but **not** the joint UV + infinite-volume limit, **not** O(4)
  restoration, and **not** the mass gap. The full 4D continuum measure
  remains unconstructed.

The honest summary: the OS-axiom program is complete in 2D (gauge) and 3D
(scalar), partial in 3D (gauge, via dynamics), and UV-only in 4D (gauge).
The 4D continuum measure with all OS axioms + mass gap is open.

## 3. On the 2025 "proof" preprints — NOT to be cited as closing it

Several 2025 preprints have circulated claiming a proof of 4D YM existence
and/or the mass gap (e.g. arXiv:2506.00284 and related notes). These are
**unrefereed and/or withdrawn**, and are **not** accepted as resolving the
problem. This project does **not** cite them as closing the Clay problem
and does **not** rely on them. The existence assumption remains open and
is treated as an explicit hypothesis.

`ContinuumYMWithGap μ_inf` extends it with the OS-reconstruction data

(`σ(H_op) ∩ (0, mass) = ∅`).

### How it bundles the existing OS axioms

The structure deliberately does **not** reinvent the OS axioms. The
`os_axioms` field IS the existing `OSAxioms.OSAxiomBundle`, whose fields
are the existing content-bearing predicates `IsOS0`,
`IsOS1HypercubicTranslation`, `IsOS1HypercubicH4`,
`IsOS2ReflectionPositivity`, `IsOS3Symmetry`, `IsOS4ClusterProperty`. The
four YM-specific fields are the additions that lift the bare OS-axiom
skeleton to the *Yang–Mills* existence problem. `withGap_carries_os_axioms`
witnesses that the OS-axiom bundle is recoverable as a projection.

### On the four YM-specific carrier predicates

The carriers `O4RestorationContent`, `GaugeGeneratedContent`,
`UVAsymptoticFreedomContent`, `NontrivialityContent` are abstract `Prop`s
(currently reflexive placeholders) whose **full** mathematical content is
open. They are kept as *distinct named predicates* — never `True` — for
two reasons: (1) an inhabitant of `ContinuumYMExistence` must supply each
by name, so no part of the Clay problem is silently discharged; (2)
strengthening any one to a substantive constructive statement is a local
edit to its carrier definition, with no change to the public field list of
the bundle or to any downstream theorem. This mirrors the abstract-Prop
style already used for the reconstruction laws (`HamiltonianNonneg`, etc.)
in `OSReconstruction.lean`.

## 5. The final-theorem wiring

`ym_mass_gap_of_existence` proves the **implication** "existence ⇒ mass
gap": given `H : ContinuumYMWithGap μ_inf`, there is a strictly positive
constructive real `m_0` with no spectrum of the reconstructed Hamiltonian
in `(0, m_0)`. The proof is a pure projection out of `H` (it returns
`H.mass`, `H.mass_pos`, `H.spectral_gap`). The existence hypothesis is the
explicit argument; it is never proven. This is the transparent replacement
for a `True` stub at the top of the mass-gap chain.

## 6. Constructivity / axiom status

Per `lean/AGENTS.md`: the module adds no `sorry`, no `Classical.*`, no
`native_decide`. The axiom gates report only `[propext, Quot.sound]`
(inherited from the structure-projection machinery), both of which are
MLTT/HoTT-valid and permitted by AGENTS.md Rule 1/8. Content-bearing data
(the Hilbert space, Hamiltonian, mass, OS bundle) is carried at the
`Type` level as structure fields, not erased into `Prop` `∃`; the
OS-axiom predicates are genuine `Prop`s, never `True`.
