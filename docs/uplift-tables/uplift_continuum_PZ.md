## Summary — GENUINE-GAIN nodes, ranked by value

All GENUINE-GAIN sits inside **SITE-1** (the only ledger-legal core-mover): the intra-block
reflection-unit-defect decomposition of the atomic `singleStep`. No other codynamic tool moves
D/F — the fold (T4) and modulus (T2) are already hand-rolled / proved orthogonal.

1. **SingleStepDefectReduction** (T1 + SITE-1) — the atomic core itself. `realδ_k` IS the
   codynamic `unit-defect`; its intra-block per-MOVE decomposition (`realδ_block ≤
   Σ_moves (∏ρ_dec)·η_move`) is the single attack a new Lean codynamic tool can legally point at.
   Also hosts the free-end δ=0 island. **Caveat (loop-risk):** legal only with a proved
   `(⋀ per-move) → singleStep` + a strictly-weaker (single local move) certificate; if per-move
   defects merely re-sum to the block object, it collapses back to `singleStep` (the trap
   `SingleStepDecompositionAdjudication` already caught once).

2. **RenDefectQuadFactor** — supplies the exact factorization `3(1−w) − (1−w³) = (1−w)²(2+w)`,
   i.e. the renormalized per-step defect is **quadratic, not linear**. This is the single
   load-bearing analytic fact the whole SITE-1 route depends on (summability of `Σδ_k` along
   `1−w_k ∼ 1/k`). Concrete T1 unit-defect priced as a square — the substrate SITE-1 folds.
