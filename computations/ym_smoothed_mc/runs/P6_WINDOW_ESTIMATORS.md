# P6 — window survival W = R(s+1)/R(s//2) under different vacuum-subtraction estimators

Data: P5 rho-scan runs (beta 2.50-2.85, 24^3x32), b2.95 32^3x48 s8 (240 meas), b3.00 32^3x48 s10 streams A+B (2x170 meas; stream C still running, excluded). Spatial Wilson flow, rho=sqrt(6 t)/s; zero-momentum s x s loop operator averaged over 3 planes. Jackknife over bins (size chosen as max(5, 4*tau_int max), shown in col 'bin'); bins never straddle streams.

Estimators: **E1** per-stream global vacuum subtraction C=<OO>_str-<O>_str^2 (pooled over streams by bin count); **E2** per-block (jackknife-bin) subtraction C=mean_b(<OO>_b-<O>_b^2); **E3f** far-lag (subtraction-free) C(n)=Q(n)-Q(Lt/2) (exact cancellation of <O>^2; bias = -C(Lt/2)); **E3d** differenced D(n)=Q(n)-Q(n+1), W_D=D(s+1)/D(s//2); **E3o** fit Q(n), n in [s//2, Lt/2], to A cosh-type single exponential + free constant K, W from the model (single-state, ignores excited states at lag s//2).

**E1c** = E1 plus bias correction: E1 is biased low by Var(<O>_stream) (constant offset in C); estimated from the bin scatter as (C_E1-C_E2)/(nbins_stream-1). Valid only if bins are independent (tau plateaued).

c0 = 2(1-W)/W, -2 log W given for E1. Sensitivity: spread = (max-min of W over E1,E1c,E2,E3f,E3d [and incl. E3o])/sigma_E1; max corr. pull = largest |W_X - W_E1| / sigma(W_X - W_E1) with the difference jackknifed (correlations kept), X in {E2,E3f,E3d} (E1c-E1 is a tiny near-deterministic shift, +0.001..0.03, so its pull is not meaningful).
