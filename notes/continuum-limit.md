# Continuum limit of the renormalized string tension

**Milestone 7.1 of `work_plan.md`.**  Prose companion to
`computations/continuum_limit.py` and
`lean/YMGap/Continuum/SigmaHatLimit.lean`.

## 1. What we're computing and why

The mass-gap theorem (Phase 9) needs a continuum-limit string tension
`σ̂_∞ > 0` to inject the area-law bound

    ⟨W_R(C)⟩  ≤  C · exp(-σ̂_∞ · A(C))

into the continuum gauge theory.  Phase 7 constructs σ̂_∞ as the
limit of the rational σ̂_k trajectory generated by the UV-direction
RG flow:

    σ̂_{k+1}  =  σ̂_k - η_k,                  σ̂_0 fixed,

where η_k is the per-step σ̂-degradation
(`computations/sigma_hat_trajectory.compute_eta`).

Telescoping gives the closed form

    σ̂_K  =  σ̂_0 - Σ_{k<K} η_k,
    σ̂_∞  =  σ̂_0 - Σ_{k=0}^∞ η_k                     (definition)
          =  σ̂_0 - total η consumed.

`σ̂_∞ > 0` is therefore equivalent to the **strict** budget closure
`Σ_k η_k < σ̂_0` — i.e. the inductive-step closure of Phase 3
strengthened from `≤` to `<`.

## 2. The two structural cases

### (i) Trivial UV pilot (η_k = 0 throughout)

In the project's current Δ_∩ derivation, `K_∩` is non-increasing as
`g_k` decreases (which holds in the UV direction), so

    Δ_∩  =  max(0, K_∩(g_next) - K_∩(g))  =  0,

hence `η_k = 0` for every k.  This gives `σ̂_∞ = σ̂_0` exactly — the
σ̂-trajectory is constant.  The limit positivity is `σ̂_∞ = σ̂_0 > 0`
(decidable when σ̂_0 = 1 : Q').

This is the case the Lean module
`YMGap/Continuum/SigmaHatLimit.lean` formalizes: a uniform Q' lower
bound `σ̂_N ≥ 1` for every N, proved as `∃ ε > 0, ∀ N, finSum η N + ε ≤ σ̂_0`.

### (ii) Non-trivially-decaying η (refined Δ_∩, future work)

A tighter Δ_∩ derivation that doesn't clip to zero would give η_k
strictly positive but geometrically decaying:

    η_k  ~  c · r_uv^k,        r_uv ≈ 1 - (b_0/16π²)·log b·g_k².

The geometric series `Σ_k η_k = c / (1 - r_uv)` converges, and σ̂_∞ =
σ̂_0 - c/(1 - r_uv) is positive iff that sum is below σ̂_0.  The Python
module exercises this case via the `eta_override` argument, and the
test `test_convergence_rate_matches_geometric_decay` confirms that the
distance |σ̂_k - σ̂_∞| decays at the same geometric rate r as η_k.

Lean formalization of case (ii) requires
`Geometric.geometric_tail_closure_strong` (Milestone 6.2-extension)
to bound the partial sums uniformly in N at a rational < σ̂_0; the
existing framework theorem `sigma_hat_uniform_positive_lower_bound`
will then compose with the strong tail bound to give the same
`∃ ε > 0, ...` conclusion as case (i).

## 3. Convergence rate

In case (i) the convergence rate is degenerate (`σ̂_k = σ̂_0` for all
k, so |σ̂_k - σ̂_∞| = 0 identically).  In case (ii) the empirical
test confirms that the distance to limit decays geometrically with
ratio matching η_k's geometric ratio r_uv — as expected from the
identity

    |σ̂_K - σ̂_∞|  =  Σ_{k ≥ K} η_k  ~  c · r_uv^K / (1 - r_uv).

## 4. g_0 dependence — open question

`work_plan.md` Milestone 7.1 raises the open analytic question:

> Whether σ̂_∞ is `g_0`-independent in the AF limit (suggesting a
> universal continuum string tension) or carries residual
> `g_0`-dependence.

In case (i), σ̂_∞ = σ̂_0 for every g_0 — degenerate
`g_0`-independence (the dependence is identically trivial).  In case
(ii), σ̂_∞ = σ̂_0 - Σ_k η_k(g_0) depends on g_0 through the η series;
whether this dependence drops out as `g_0 → 0` is the genuine open
question.  The Python helper `compare_g0_dependence` sweeps over a
list of initial couplings; when case (ii) lands, that helper is the
empirical test for AF-limit universality.

## 5. Framework Lean theorem (what's in `SigmaHatLimit.lean`)

The load-bearing Lean theorem of Milestone 7.1 is

    sigma_hat_uniform_positive_lower_bound :
      ∀ (η : QSeq) (bound σ_0 ε : Q'),
        (∀ N, finSum η N ≤ bound) →
        (bound + ε ≤ σ_0) →
        (∀ N, finSum η N + ε ≤ σ_0)

— a generic framework theorem.  It composes with any of the Phase-6
partial-sum-bound providers:

  * `sigma_hat_budget_closure` (Phase 3.4 finite-truncation form),
  * `prefix_plus_tail_closure` (Phase 3.4-tail infinite-trajectory form),
  * `geometric_tail_via_input` (Phase 6.2 geometric-series form),
  * `eta_pilot_uv_partial_sum_bound` (Phase 6.4 UV-pilot zero case).

The UV-pilot instantiation is

    sigma_hat_uv_limit_positive :
      ∃ ε : Q', (0 < ε) ∧ (∀ N, finSum eta_pilot_uv N + ε ≤ sigma_hat_0_pilot_uv)

with witness ε = 1 (since `finSum eta_pilot_uv N = 0` and σ̂_0 = 1).

**Axiom-gate**: every theorem in the module reports `[propext]` only.

## 6. Scope honesty: what 7.1 does NOT deliver

  * **A single `σ̂_∞ : Real` value in Lean**: requires a constructive-reals
    layer (Cauchy sequences of Q' with explicit modulus, decidable
    equality and ordering on the limit), scoped as Milestone 7.3.  The
    current module gives the equivalent framework form (uniform
    positive lower bound on every partial σ̂_N), which is what σ̂_∞ > 0
    *means* in the absence of the reals layer.
  * **Case (ii) Lean closure**: requires `geometric_tail_closure_strong`
    (Milestone 6.2-extension).  Numerically supported in
    `computations/continuum_limit.py`; Lean composition pending the
    strong tail closure.
  * **Continuum measure construction (μ_∞)**: separate milestone (7.2),
    much heavier analytical machinery.
